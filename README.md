# Projet POO : jeu du démineur / Clara Bouvier

Pour lancer le jeu, ouvrez un terminal, mettez-vous dans le dossier du dépot et lancez la commande 'python main.py'.

Il y a, dans le dossier "diagrammes", un diagramme de classe, un diagramme de cas d'utilisation, un diagramme de séquence de "découvrir une case" et un diagramme d'états-transitions d'une partie.

## Règles du jeu : 

A chaque coup, vous pouvez :

- marquer une case pour signifier que c'est une case minée,
- enlever la marque d'une case,
- découvrir une case.

Vous perdez quand vous découvrez une mine.

Vous gagnez soit quand :
- vous avez marqué exactement toutes les cases minées,
- vous avez découvert toutes les cases vides et numérotées.

Il n'y pas de temps imparti ou de nombre de coup maximum.

Au début du jeu, vous devez choisir un niveau de difficulté (facile, moyen, difficile). 
Ensuite, vous devez écrire le coup que vous voulez réaliser jusqu'à ce que vous gagniez ou perdiez. Le jeu vous propose de rejouer, vous pouvez accepter et rejouer ou refuser et le jeu s'arrête.
